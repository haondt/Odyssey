# Odyssey

A self-hosted, real-time gameshow platform

### Tech stack

- ASP.NET Runtime
- Blazor SSR
- SignalR (Websockets)
- HTMX + Hyperscript
- .NET Orleans
- Entity Framework Core
- PostgreSQL

# Development Guide

### Preqrequisites

- .NET 10
- [dcdn](https://github.com/haondt/dcdn)
- [bun](https://bun.com/)
- [docker](https://www.docker.com/)
